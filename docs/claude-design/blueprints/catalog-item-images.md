## Layout — หน้าจอกรอกข้อมูล (frame ที่ approve)

```
┌─ #DK-01234 ──────────────────────────────────  [↑] [↓] [ลบชิ้นนี้] ─┐
│                                                                     │
│  คำอธิบาย บรรทัด 1  [ 18K GOLD RING 1.91 G..................... ]   │
│  คำอธิบาย บรรทัด 2  [ 17PCS DIAMOND 0.09 CT.................... ]   │
│                                                                     │
│  ขนาดสินค้า   ความสูง [ 1.8 CM..... ]   ความกว้าง [ 1.6 CM..... ]    │
│              พิมพ์เป็นเส้นบอกขนาดรอบรูปในไฟล์ PDF                      │
│                                                                     │
│  รูปสินค้า   ใส่ได้ 1–3 รูป · รูปแรกคือรูปหลัก                          │
│  ┌──────────────┐  ┌──────────────┐   ┌ ─ ─ ─ ─ ─ ─ ┐               │
│  │              │  │              │   │             │               │
│  │   [รูปหลัก]   │  │   [รูปที่ 2]  │   │  ＋ เพิ่มรูป  │               │
│  │          [✕] │  │          [✕] │   │             │               │
│  └──────────────┘  └──────────────┘   └ ─ ─ ─ ─ ─ ─ ┘               │
│    [◀] [▶]           [◀] [▶]           (ปุ่มหายเมื่อครบ 3)             │
│                     คำบรรยาย [ ด้านข้าง....... ]                       │
└─────────────────────────────────────────────────────────────────────┘
```

**กฎการแสดงผล**

- ช่องรูปเป็น **รายการต่อเนื่อง** — ไม่มีช่องว่างคั่นกลางได้อีกแล้ว
- ปุ่ม `＋ เพิ่มรูป` แสดงเมื่อรูป < 3 · ซ่อนเมื่อครบ 3
- ปุ่ม `✕` บนรูป = ลบรูปนั้น รูปที่เหลือขยับชิดซ้ายเอง
- ปุ่ม `◀ ▶` เลื่อนลำดับรูป · `◀` ซ่อนที่ใบแรก · `▶` ซ่อนที่ใบสุดท้าย
- ช่อง **คำบรรยาย** แสดงใต้ **รูปสุดท้ายเท่านั้น** และเฉพาะเมื่อมีรูป ≥ 2 (รูปเดียวไม่มีคำบรรยาย ดู §เลย์เอาต์ PDF)
- ไม่มีรูปเลย → แสดงเฉพาะปุ่ม `＋ เพิ่มรูป` (ไม่ใช่กล่องเปล่า 3 ใบ)

## Spec — ค่าที่ใช้

### ขนาดรูปตามจำนวน

| จำนวนรูป | รูปเอก | รูปรอง | เส้นบอกขนาดเกาะรูปไหน | คำบรรยายใต้รูปสุดท้าย |
|---|---|---|---|---|
| 1 รูป | `290` pt | — | รูปเอก | ไม่แสดง |
| 2 รูป | `260` pt | `175` pt | รูปที่ 2 | ใต้รูปที่ 2 |
| 3 รูป | `230` pt (เดิม) | `135` pt × 2 (เดิม) | รูปที่ 2 (เดิม) | ใต้รูปที่ 3 (เดิม) |
| 0 รูป | — | — | ไม่แสดง | ไม่แสดง |

- กรณี 0 รูป: วาดกรอบเส้นประ **1 ใบ** เป็นสัญญาณตอน preview (ไม่ใช่ 3 ใบ) + เตือนที่หน้าจอก่อนกด Preview/Download
- ค่าคงที่เดิมที่ยังใช้: `DIMTXT_W = 36`, `VLINE_W = 10`, `CONTENT_W = 762`, หน้า `842 × 474`
- พื้นที่คอลัมน์ขวา ≈ `533` pt กว้าง × ≈ `300` pt สูง — ทุกแบบต้องไม่ล้น (A·2 = 260+20+46+175 = 501 ✓ · A·1 = 46+290 = 336 ✓)
- `fitBox(ratio, side)` เดิมยังใช้ต่อ — รูปที่อัตราส่วนไม่ใช่ 1:1 ย่อให้อยู่ในกรอบด้านที่กำหนด

### สีและเส้น (คงเดิมทั้งหมด)

## ความหมายของฟิลด์ขนาด (แก้ป้ายชื่อ)

ปัจจุบันหน้าจอเขียน “ป้ายขนาด” เหมือนกัน 3 ช่อง แต่โค้ด PDF ใช้คนละความหมาย — เปลี่ยนป้ายให้ตรงของจริง **ไม่ต้องย้ายข้อมูลใน DB**

| ฟิลด์ | ป้ายเดิม | ป้ายใหม่ | ใช้ทำอะไรใน PDF |
|---|---|---|---|
| `dimension1` | ป้ายขนาด (ใต้รูป 1) | **ความสูง** | เส้นวัดแนวตั้งด้านซ้ายของรูปที่มีเส้นบอกขนาด |
| `dimension2` | ป้ายขนาด (ใต้รูป 2) | **ความกว้าง** | เส้นวัดแนวนอนด้านบนของรูปเดียวกัน |
| `dimension3` | ป้ายขนาด (ใต้รูป 3) | **คำบรรยาย** | ข้อความใต้รูปสุดท้าย |

`dimension1` + `dimension2` ย้ายขึ้นไปเป็นกลุ่ม **“ขนาดสินค้า”** เหนือแถวรูป (เพราะเป็นขนาดของสินค้า ไม่ใช่ของรูปใดรูปหนึ่ง)

## Data flow — ปิดบั๊กรูปเลื่อนช่อง

```
เดิม   หน้าจอ: [ null , null , รูปC ]
      ─ save ตัด null ทิ้ง ──▶  ส่ง [ รูปC ]        เก็บ sort_order = 0
      ─ load อ่าน sort_order 0 ──▶  [ รูปC , null , null ]   ← เลื่อนไปช่อง 1

ใหม่   หน้าจอ: [ รูปA , รูปB ]     (รายการต่อเนื่อง ไม่มีช่องว่างตรงกลาง)
      ─ save ส่งทั้งรายการตามลำดับที่เห็น ──▶  sort_order = 0, 1
      ─ load เรียงตาม sort_order ──▶  [ รูปA , รูปB ]        ← ตรงกันเสมอ
```

| ชั้น | ต้องแก้ | ย้ายข้อมูลเดิม |
|---|---|---|
| DB `tbt_sale_document_catalog_item_image` | **ไม่แก้** — รองรับกี่แถวก็ได้อยู่แล้ว | ไม่ต้อง |
| API `SaveRequest.ImageBlobPaths` / `BuildItems` | **ไม่แก้** — เป็น `List<string>` ความยาวอิสระ | ไม่ต้อง |
| UI store/view | เก็บรูปเป็น array ต่อเนื่อง · เลิก `.filter(Boolean)` ตอน save · load ตัด `null` ออกให้ต่อเนื่อง | ไม่ต้อง |
| PDF builder | เลือกเลย์เอาต์ตามจำนวนรูปจริง · ตัดกล่อง `[รูป n]` | ไม่ต้อง |

> แคตตาล็อกเก่าที่บันทึกไว้แล้วเปิดขึ้นมาต้องได้หน้าตาเดิมทุกประการ (กรณี 3 รูป = A·3 ไม่เปลี่ยน)

## Diff จากของเดิม

- ช่องอัปโหลด `3 ช่องตายตัว` → `1–3 ช่องยืดหยุ่น` + ปุ่มเพิ่ม/ลบ/เลื่อนลำดับ
- ป้าย `ป้ายขนาด × 3` → `ความสูง` + `ความกว้าง` (กลุ่ม “ขนาดสินค้า”) + `คำบรรยาย` ใต้รูปสุดท้าย
- PDF: กล่องเปล่า `[รูป 2] [รูป 3]` → **ตัดออก** เหลือกรอบเส้นประ 1 ใบเฉพาะกรณีไม่มีรูปเลย
- PDF: เส้นบอกขนาดผูกกับ `img2` เสมอ → ผูกกับ “รูปที่มีเส้นบอกขนาด” (รูปเอกเมื่อมีรูปเดียว)
- PDF: ขนาดรูปคงที่ `230 / 135 / 135` → ปรับตามจำนวน `290` · `260+175` · `230+135+135`
- save/load: `.filter(Boolean)` + เดา index → array ต่อเนื่อง sortOrder ตรงกันสองทาง
- เพิ่ม warning เมื่อมี item ที่ยังไม่มีรูปก่อน Preview/Download
